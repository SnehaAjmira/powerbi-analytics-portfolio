# Pareto (80/20) Analysis: Clients and Tests

Shows which clients and which tests generate most of the lab's revenue and volume. A what-if parameter moves the cut-off (for example 80%), and every client or test is split into an "A+" group above the line and "Others" below it. 4 pages, 50 DAX measures.

> Data is synthetic (fictional "Contoso Analytical Labs"): ~860,000 test records from 2023 to October 2026 for ~1,500 client facilities, generated by [`generate_lab_data.py`](../data-generator/generate_lab_data.py).

![Client revenue Pareto](screenshots/client-rev-pareto.png)

## Pages

Client Revenue Pareto, Client Volume Pareto, Test Revenue Pareto, Test Volume Pareto.

## How it works

- `RAW_2023` to `RAW_2026` are appended in Power Query into `AllData`.
- `Client split category` and `Test split category` are `CROSSJOIN`s of each client or test with the categories "A+" and "Others", so one visual can show both groups side by side.
- Running totals use the DAX `WINDOW` function ordered by revenue or volume:

```dax
Client Rev Contrib Run Total =
IF (
    [Total Revenue],
    CALCULATE (
        [Client Rev Contrib %],
        WINDOW ( 1, ABS, 0, REL, ALL ( 'Client split category'[Client] ),
                 ORDERBY ( [Total Revenue], DESC ) )
    )
)
```

- `Client Rev RT Split` returns the running total only for the category the client belongs to at the selected cut-off, which draws the two-color Pareto curve.
- `A+ Client Count (Rev)` counts how many clients make up the selected share of revenue.
